# Trilium 阅读主题 · Blue / gnome

基于 [SiriusXT/trilium-theme-blue](https://github.com/SiriusXT/trilium-theme-blue)，保留蓝色界面、米黄色浅色背景、霞鹜文楷和彩色树形引导线，重新整理长文排版与明暗主题的交互状态。适用于以 TriliumNext `next-light` / `next-dark` 为基础的自定义主题（原主题要求 >= 0.101.1）。

新增独立的 **gnome** 暗色主题：参考 Emacs 截图中的青墨底、米金文字和橄榄色标签，适合中文长文、日常笔记和代码阅读。原有 Blue light / dark 继续保留。

## 使用

三份 CSS 都是完整、独立的文件，不依赖额外 CSS、构建步骤或外部在线字体。

| 文件 | CSS 笔记属性 |
| --- | --- |
| `blue-theme-light.css` | `#appTheme=blue-theme-light #appThemeBase=next-light` |
| `blue-theme-dark.css` | `#appTheme=blue-theme-dark #appThemeBase=next-dark` |
| `gnome.css` | `#appTheme=gnome #appThemeBase=next-dark` |

1. 在 Trilium 创建 CSS 类型的代码笔记，粘贴对应文件的完整内容。
2. 添加上表中的属性，在选项的外观设置中选择主题。
3. 修改主题或图片脚本后，通过 Ctrl+R（macOS 为 Cmd+R）重新加载。

不要同时将这些 CSS 标记为 `#appCss`；应通过主题选择使用其中一份。

## gnome · Emacs 暗色阅读主题

使用截图中提取的三个主色：青墨背景 `#192a2b`、米金正文 `#f2d7a4`、橄榄色选中底 `#2f3e19`。侧栏和工具栏略深，菜单与引用略亮；默认使用纯色背景，完全不依赖侧栏图片。gnome 是本仓库的自定义主题名称，配色以用户提供的 Emacs 截图为依据。

| 元素 | 颜色 / 处理 |
| --- | --- |
| 阅读区 / 正文 | `#192a2b` / `#f2d7a4`，对比度 **10.68:1** |
| 侧栏 / 工具栏 | `#182627` / `#162323`，界面文字为暖灰米色 `#c0b69c` |
| 选中 / 焦点 | 橄榄色底、持久侧线或顶线，焦点色 `#c1c78f` |
| 标题 | H1 米金、H2 橄榄色细侧线、H3 灰绿，低层级逐步收敛；H1–H6 对比度最低 **7.69:1** |
| 链接 | 灰青色 `#9fcfdf`，保留下划线 |
| 文本笔记中的代码块 | 深青墨底、灰青斜体注释、珊瑚色关键字、薄荷绿字符串 |
| 表格 / 引用 | 同一青墨色系中的轻微明度变化，细边框与可见的编辑焦点 |

- 延续文楷、正文 `1.2rem`、行高 `1.75` 及普通段落两字符首行缩进。编辑态与只读态保持同样的字号和缩进；内容宽度沿用 Trilium 设置。
- 笔记树采用单一低饱和灰绿分支线，活动节点另有橄榄色底和侧线。标签页保留工作区颜色标记；原生笔记自定义色继续由基础主题处理。
- 同时适配纵向 / 横向工具栏、搜索、输入框、主要按钮、菜单、弹窗、提示及 CKEditor 工具栏。主操作按钮使用橄榄色；错误、危险操作和警告保留语义颜色。
- 文本笔记代码块的默认文字对比度为 **11.07:1**，语法颜色最低为 **7.61:1**；表头为 **7.44:1**，浮层上的次要文字为 **5.18:1**。低对比分隔线仅用于装饰，选中和焦点另有清晰标记。
- 长代码在块内横向滚动，开启代码自动换行后随设置换行；保留原生复制按钮、表格调整控件及手动指定的单元格样式。
- **独立代码笔记**使用 Trilium 单独配置的代码编辑器主题。`gnome.css` 不接管 CodeMirror 的独立主题；本主题的语法配色用于文本笔记中的代码块。
- 打印转换为白底黑字，取消彩色标题、代码底色及单元格选区，展开长代码。图片保持原样；需要白底图表自动适配时，可使用下方可选脚本，gnome 的暗色标记与其兼容。

调整入口位于 `gnome.css` 文件开头：`--gnome-ink` 为正文底色，`--gnome-text` 为正文颜色，`--gnome-olive` 为强调色；字号、`--gnome-reading-line-height` 与 `--gnome-paragraph-indent` 位于后面的排版变量区。无需修改其他主题文件。

验证使用本机 0.106.1 的实际基础样式，在隔离 Chromium 页面覆盖编辑 / 只读、纵向 / 横向布局、340px 窄内容区、代码自动换行及打印样式，共 10 组组合、350 项样式断言；另检查 CSS 语法、变量完整性与配色对比度，并目视检查桌面和窄内容区渲染。打印验证通过应用实际的 `@media print` 规则检查计算样式，未验证实体分页；隔离页面不等同于完整 Trilium / CKEditor 操作集成测试。

## Blue 设计方案

参考 [Primer 的标题层级](https://primer.style/product/components/heading/)、[Material 的字体角色与对比度](https://m3.material.io/styles/typography/applying-type)及 [GOV.UK 的标题规范](https://design-system.service.gov.uk/styles/headings/)。以下配色与布局是为本主题设计的方案，并非直接复制这些设计系统的样式。

层级先通过字号、间距和边线表达，颜色作为辅助。移除原来的白字、文字阴影和发光色块；每个标题都有独立字号，不要求读者仅凭颜色区分层级。保留 Trilium 设置中的 Markdown `#` 前缀，将它们缩小；不修改笔记本身的标题语义。

| 层级 | 相对正文字号 | 视觉处理 | 浅色文字 / 深色文字 |
| --- | --- | --- | --- |
| H1 | 1.85em | 蓝色大标题、细底线 | `#244b67` / `#d6e6f4` |
| H2 | 1.50em | 淡蓝底、左侧边线 | `#254f6c` / `#b8d9f3` |
| H3 | 1.30em | 青绿色文字、左侧边线 | `#2f6259` / `#a8d5c7` |
| H4 | 1.15em | 暖棕 / 沙金色文字 | `#79542b` / `#dfc29b` |
| H5 | 1.05em | 灰紫色文字 | `#625375` / `#c7b8de` |
| H6 | 1.00em | 灰蓝色文字 | `#565e64` / `#b8c3cc` |

H2 的浅色底为 `#e1e9e8`，深色底为 `#273847`；其余标题使用正文底色。在默认配色下，H1–H6 的文字对比度浅色最低为 **5.62:1**、深色最低为 **8.18:1**，均高于普通文字 4.5:1 的参考值。链接保持下划线，并分别使用较深的蓝色和较亮的蓝色。参考 [WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

### 字体与阅读节奏

- 主界面与笔记树使用 `1.1rem`，正文使用 `1.2rem`，代码编辑区使用 `1rem`，避免嵌套 `em` 反复放大。浏览器根字号 16px 时分别约为 17.6px、19.2px、16px；页面缩放仍正常生效。
- 保留 `LXGW WenKai` / `LXGW WenKai Mono`，并补充楷体、系统等宽字体回退。设备没有安装文楷时将使用回退字体；若要跨设备保持一致，可参考 [Trilium 的字体资源说明](https://docs.triliumnotes.org/user-guide/theme-development/reference#custom-fonts)配置字体。
- 正文行高为 1.75，普通顶层段落保留两字符首行缩进及两端对齐；列表、任务清单、表格、引用和图注使用自然对齐。
- 正文排版限定在编辑态与只读态容器，标题装饰排除笔记列表卡片、笔记本标题及嵌入笔记的标题控件。
- 内容宽度继续由 Trilium 的外观设置管理，避免主题覆盖全宽笔记或分栏。以默认正文字号阅读中文长文时，可先试 900–960px 并启用居中，再按屏幕调整。参见 [内容宽度设置](https://docs.triliumnotes.org/user-guide/concepts/ui/content-width)。

### 代码块与表格

参考 [Carbon 的代码片段规范](https://v10.carbondesignsystem.com/components/code-snippet/usage/)中关于留白与长行滚动的处理，以及 [Carbon 的表格规范](https://v10.carbondesignsystem.com/components/data-table/style/)中的表头层次、行间距、交替底色和焦点状态。结合现有米黄正文、蓝色界面与青绿标题，采用低饱和的阅读配色；不增加拟窗口按钮或额外工具栏。

| 元素 | 浅色 | 深色 | 排版与交互 |
| --- | --- | --- | --- |
| 代码块 | 蓝灰底 `#edf1f3`、墨蓝字 `#283c49` | 深蓝灰底 `#232d35`、浅灰蓝字 `#d8e3eb` | 6px 圆角、细边框、顶部蓝线，取消阴影 |
| 语言标签 | 淡蓝底、灰蓝字 | 深蓝底、浅蓝字 | 保留原生语言名称，独立留出顶部空间，不遮挡首行 |
| 表格正文 | 暖白与淡灰绿交替 | 深灰蓝交替 | 正文的 95% 字号、1.6 行高、等宽数字，细分隔线 |
| 表头 | 淡蓝底 `#e0e9ec`、深蓝字 | 深蓝底 `#2b4050`、浅蓝字 | 半粗字重，同时支持表头行和表头列 |

- 代码块继续使用主题的等宽字体和 `--monospace-font-size`，行高为 1.65；高亮按蓝、绿、紫、暖棕区分语法角色。默认代码文字对比度浅色为 **10.08:1**、深色为 **10.75:1**；语法颜色最低分别为 **4.75:1**、**6.17:1**。表头文字分别为 **7.06:1**、**7.61:1**。
- 长代码默认在块内横向滚动；开启 Trilium 的代码自动换行后随之换行。只滚动内部 `code`，外层保持可见，避免裁切代码前后插入段落的控件。保留原生复制按钮和工具栏；只读视图没有原生语言标签时不伪造标签。
- 行内代码使用轻底色、小圆角，并允许长路径换行。代码块内部不叠加行内代码的字体缩放和留白。
- 表格使用轻微交替底色和鼠标悬停反馈，活动单元格与多单元格选区分别保留可见提示。编辑态不裁切表格容器，以保留列宽调整和控件；只读态允许宽表格在容器内横向滚动。普通长链接和标识符可以在单元格内换行。
- 保留手动指定的宽度、单元格底色、文字颜色、边框和对齐，不用 `!important` 覆盖这些内容样式。合并单元格沿用原生结构。只有真正的 `th` 使用表头色；已有表格若第一行仍是普通单元格，可在 Trilium 的表格工具栏将其设为标题行。
- 样式限定在 text 笔记的编辑和只读内容中，排除笔记列表卡片与布局表格；不修改独立代码笔记、集合表格或应用全局表格。语法配色仅处理应用已经生成的高亮标记，不改变语法识别与高亮开关。
- 打印时改为白底黑字、细灰边框，展开长代码，隐藏语言标签、复制按钮、编辑辅助控件与选区色，尽量避免将一行表格拆到两页。

配色集中在文件前部的 `--blue-code-*`、`--blue-syntax-*`、`--blue-inline-code-*`、`--blue-table-*` 和 `--blue-caption-text` 变量中，两份 CSS 仍可独立粘贴使用。

### 侧栏、焦点和打印

- 左侧栏沿用 `../../../custom/background.png`。浅色叠加 90% 的浅色遮罩，深色叠加 94% 的深色遮罩，减弱纹理并保护文字对比度；缺少图片时仍有主题底色。相对资源路径保留对部署子路径的兼容。
- 树节点的悬停与活动状态使用不同背景，活动节点还有持久边线；彩色分支线只承担结构提示。
- 恢复可见的键盘焦点与编辑器表格焦点，不再将全局焦点颜色设为透明，也不隐藏侧栏的滚动条。
- 滚动条使用基础主题的颜色变量，代码块可保留自己的局部配色；标签页恢复省略号。
- 打印时，编辑态和只读态的 H1–H6 都转换为黑字、透明背景，保留字号层级与标题后的分页约束。取消整组 `all: revert`，不隐藏笔记标题或警告内容。
- 减少动画的规则仅在系统启用 `prefers-reduced-motion` 时应用。

可在 CSS 的变量区调整 `--blue-reading-line-height`、`--blue-paragraph-indent`、`--blue-wallpaper-overlay` 和 `--blue-heading-*`。不需要纹理时，将 `--blue-wallpaper-image` 改为 `none`；不需要首行缩进时，将 `--blue-paragraph-indent` 改为 `0`。

## 可选的深色图片脚本

在 JavaScript 代码笔记中粘贴 `Dark-mode-img-color-conversion.js`，添加 `#widget`。给某篇笔记添加 `#disableAdjustImage`，可对该笔记关闭图片反色，保留深色高亮适配。

- 图片在加载和识别期间正常显示；仅对白色不透明背景占比高的图片应用反色。照片等未命中的图片不再统一降低亮度。
- 通过图片加载事件及 DOM 观察处理粘贴、懒加载和换图，取代固定时间的扫描和轮询。
- 采样最多 64×64 像素，避免大图造成不必要的像素遍历；透明图、读取失败和损坏图片保留原样。
- 高亮转换只作用于处于深色模式的当前笔记面板，浅色模式、其他界面和打印不会被修改。观察器在切换笔记和销毁时清理，多个分栏各自管理。

白底比例仍属于启发式判断：白底照片也可能命中，可使用上述标签关闭。脚本不修改原始图片文件。

## 维护与验证

三份 CSS 均可独立粘贴使用。两份 Blue CSS 的公共排版与交互规则保持一致；gnome 独立维护截图配色、应用状态及只读排版适配。主题特有的配色集中在各文件前部。

阅读版此前在隔离 Chrome 页面中验证了明暗配色、H1–H6 对比度、编辑与只读一致性、焦点、选择器边界、列表和表格缩进、滚动条、树节点状态及打印；另验证了图片新增、换源、透明图、读取失败、禁用标签、主题切换与观察器清理。

代码块与表格这一轮使用本机 Trilium 安装包中的 CKEditor、全局及 Next 内容样式搭建隔离页面，验证了明暗、只读、340px 窄内容区、自动换行及打印样式共 10 组组合，检查语法对比度、滚动、容器溢出、表头、交替行、活动单元格、选区覆盖层、合并单元格、自定义样式和选择器边界。打印检查通过应用实际打印规则进行样式验证，未验证实体分页；隔离页面也不等同于完整 CKEditor 操作集成测试。测试、预览与构建辅助文件不保留在仓库中。
